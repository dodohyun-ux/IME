# 운행 결과 배경지도

2026-10-05 사용자 요청으로 기존 결과 카드의 SVG 경로를 인터랙티브 지도로 교체했다.

- 경로: 최적화 출력의 GUGiK 도로 선형. 배경지도가 새 경로를 계산하지 않는다.
- 배경: OpenStreetMap Standard 온라인 타일. 지도 오른쪽 아래 저작자 표시를 유지한다.
- UI: 배송/복귀 전환, 차량 운행 선택, 창고/구호소 표식과 주소 팝업,
  확대/축소, 전체 경로 보기, 크기 변경 시 전체 경로 자동 맞춤.
- 원래 운행표/비용/휴식 표시와 전체 카드 디자인을 유지한다.
- 타일 실패 또는 15초 이상 지연되면 연결 안내를 표시한다. 계산된 경로는 남는다.
- 마우스 휠은 페이지 스크롤에 사용하고 지도 확대 버튼/터치/키보드를 제공한다.
- 좌표는 GeoJSON [경도,위도]를 Leaflet [위도,경도]로 변환한다.

예측/최적화/API 수정 없음. 실시간 교통, 도로 통제, 시설 진입 확인을 추가한 것이
아니며 배경지도와 계산 경로의 작은 위치 차이가 있을 수 있다. 표식은 주소 가까운
도로 끝점이다. 오프라인 배경지도나 대량 타일 다운로드는 제공하지 않는다.
타일 공급자의 가용성은 보장되지 않는다. 공개 배포/병합은 수행하지 않았다.

## 확인

TypeScript --noEmit과 Vite build 통과. 기존 example_official_result.json의
Medyka 2개 운행으로 브라우저에서 배경 타일 로딩, 배송/복귀, 운행 선택,
확대/전체 경로, 390px 반응형 배치와 끝점 표시를 확인했다. React StrictMode도
사용했다. 테스트 중 축약 운행표를 사용한 최초 미리보기 오류는 fixture를 전체
응답으로 바꿔 해결했다. 통신 실패 안내는 구현했지만 외부 서버 장애를 유도하는
브라우저 검증은 수행하지 않았다. screenshot: ui-road-map.jpg.

## 공식 문서

- [Leaflet 1.9.4 API](https://leafletjs.com/reference.html)
- [OSMF 타일 사용 정책](https://operations.osmfoundation.org/policies/tiles/)
- [OpenStreetMap 저작권](https://www.openstreetmap.org/copyright)

정책 확인일 2026-10-05. HTTPS 표준 URL, 화면 내 출처, 브라우저 Referer와
기본 HTTP 캐시를 사용하며 현재 화면 밖 타일 버퍼는 0이다. 지도/화물 API
응답을 외부 지도 서버에 업로드하지 않는다. 브라우저의 지도 타일 요청은 일반
접속 정보와 열람 지역을 지도 서버에 제공한다.
