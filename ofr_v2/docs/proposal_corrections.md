# 기획서 정정 목록 (2026-09-30)

대상: 기획서 "커플외2명 이공학술제" 1절(최적화 모델)과 2절(프로젝트 개요). 왼쪽이 현재 문구, 오른쪽이 코드(`app/backend/optimization.py`, `weekly_forecast.py`)에 맞춘 수정안입니다.

## A. 수식 오류 (바로 고칠 것)
| # | 현재 | 수정 | 이유 |
|---|---|---|---|
| A1 | 비음수 `X, Y, I, U ≤ 0` | `X, Y, I, U ≥ 0` | 부등호 방향 오기 |
| A2 | `min Z = Σ_{i∈I} * ω_i * (ΣΣU)/(ΣΣD)` | `min Z = Σ_{i∈I} ω_i · (Σ_s Σ_t U_sit) / (Σ_s Σ_t D_sit)` | 불필요한 `*` |
| A3 | 변수표는 `B_t = t주의 예산`, 제약식은 `Σ c_i X_sit ≤ B` | 둘 다 **계획 기간 총예산 B**로 통일 | 구현은 총예산 하나 |
| A4 | 정수 제약이 `X_sit`에만 있음 | `X_sit, Y_sit, U_sit, I_sit ∈ ℤ≥0, i ∈ {F, H, B}` | 구현은 네 변수 모두 정수 |
| A5 | 식량 수요가 표에서는 `D = 2100·d·P`(kcal), 식에서는 `D = d·P` | **1일분(2,100kcal) 단위**로 통일: `D_sFt = d·P_st` | 단위 혼재 |
| A6 | `P_st = r·N_st` | `P_st = ⌈r·N_st⌉` | 구현은 올림(사람 수는 정수) |
| A7 | 초기 재고 표기 `I_si` | `I_si0`로 쓰고 재고식 `I_sit = I_si,t−1 + X_sit − Y_sit`의 t=1에 사용한다고 명시 | 기말 재고 `I_sit`와 기호 충돌 |

## B. 빠진 부분 (구현에는 있음)
| # | 추가할 내용 |
|---|---|
| B1 | **3단계 사전식 최적화.** ① 최대 미충족률 z 최소화 ② ①을 고정하고 가중 정규화 미충족(현재 목적함수 Z) 최소화 ③ ①②를 고정하고 조달비용 `Σ c_i X_sit` 최소화 |
| B2 | 공정성 제약 `U_sit ≤ z · D_sit (D_sit > 0)`, `0 ≤ z ≤ 1` |
| B3 | 우선순위 옵션: 공정성 우선(①부터) / 효율 우선(①을 건너뜀). 예시 입력에서 평균 충족률 73.8% vs 81.1% |
| B4 | 솔버: `scipy.optimize.milp`(HiGHS). 풀이 후 모든 제약을 다시 검증 |

## C. 개요(요약·목표·방법)와 구현의 불일치
| 개요 문구 | 실제 구현 | 권장 수정 |
|---|---|---|
| UNHCR 국경별 난민 통계 | 폴란드 국경수비대 일별·통과지점별 데이터(`ewakuowani`) | 데이터 출처 교체 |
| XGBoost, LightGBM | scikit-learn HistGradientBoosting(분위수 회귀) | 모델명 교체 |
| 일주일 뒤 예측 | 1~4주 뒤 주간 예측(직접 다중시점) | 교체 |
| 분쟁 강도를 변수로 입력, 교차상관으로 시차 추출 | 검토했으나 성능이 나빠져 제외(검증 16.0% vs 14.9%), ACLED가 2025-07에서 끝남 | "검토 후 근거 부족으로 제외"로 서술 |
| 수용 국가 예측, 대피소별 이동 확률 | 없음. 구호소 3곳의 통과 인원을 직접 예측 | 삭제 |
| MAE로 검증 | 롤링 백테스트, WAPE·MAE, 80% 구간 적중률, 나이브 대비 유의성 | 교체 |
| 선형보간·MICE로 결측 보완 | 해당 없음(국경 데이터에 결측 없음) | 삭제 |
| PuLP + CBC, 트럭 배차 수, 수송 경로 | scipy milp(HiGHS), 품목별 발주량·배분·재고. 차량·경로는 없음 | 수송·경로는 "향후 과제"로 이동 |
| Streamlit 대시보드 | React + FastAPI 웹앱 | 교체 |
| (없음) | 분석 범위 2022-02-28 ~ 2026-02-23 주. 2026-03-05 특별법 종료로 통계 정의 변경 | 데이터 절에 추가 |
