## 재개 후 결과

이전 저장 시점은 원문 135문서/미취득 타일 35개였고 Dorohusk 경로가 단절됐다.
재개 후 실패 타일만 세분해 106문서를 추가했다. 현재 manifest는 241문서와
34개 미취득 작은 타일을 기록한다. 원문 복원 후 SHA256을 확인한다.
**두 창고 후보에서 세 구호소 모두까지 선형 경로가 연결됐다.** 최신 거리는
facility_validation.json을 기준으로 확인한다. 전국 도로망 완성률이 아니다.
도로 취득 workflow는 수동으로 복귀했으며 예약·자동 재시도는 없다.

Dorohusk 선택 지역은 중복 제거 RoadLink 122,931개다. 필요한 가지를 남긴 그래프는
71,938노드 / 195,160방향 간선이다. 기존 끝점 연결만 사용하며 빠진 구간을 직선으로
메우지 않는다. 출처 feature/좌표는 결과 왕복 경로에 남는다.

차량 kg/m³, 도로 높이·폭·총중량·품목·폐쇄·공유 진입 용량, 조달/운송 시각,
FEFO·만료·폐기·예산·재고·수요를 개별 트럭 적재·출발·도착·복귀와 공동 계산한다.
대형 그래프는 Yen/A* 경로 후보 집합 안에서만 최적화하며 출발 격자도 명시한다.

휴식은 왕복 전체의 연속 운전을 보고 도달 가능한 허용 노드에 삽입한다.
필요하면 도착 이전에도 쉰다. 하역은 휴식이 아니다. 도착지 휴식은 기본 금지이며
`--destination-rest-permission`은 명시적 시나리오 가정이다. 장거리 실제 선형
검증에서는 이 가정을 켜면 계획이 나오고 끄면 해당 운행이 거부된다.
모든 선택적 휴식 시점을 열거하지 않으므로 다른 시점의 가능한 운행이 빠질 수 있다.
최신 전체 테스트와 smoke 결과는 WORKLOG와 PR 검사에 기록한다.

## 이어서 현실 검증할 일

1. 실제 창고의 현재 운영·계약·물품/차량 용량과 하역장을 확인한다.
   Lwowska 36 / Wodna 11은 2022년 시청 근거의 조사 후보이며 현재 사용 승인은 미확인이다.
2. 공식 주소점은 트럭 출입구가 아니다. Medyka 293/285 주소 충돌,
   Korczowa 155/별도 Hala Kijowska 구분, Dorohusk-Osada Parkowa 5를 현장과 대조한다.
3. 실제 차량·제품 포장·속도·일방통행·총중량/축하중·높이·폭·운영창·실시간
   폐쇄·기사 휴식 장소 승인 자료를 입력한다. 허용값을 임의로 완화하지 않는다.
4. 현장 GPS/운송 실적과 거리·도착 시각을 대조한다. 원문 feature의 2015~2023년
   버전과 2026년 수집일을 구분한다. 미취득 타일은 현재 연결을 막지 않지만
   다른 경로의 누락·최적성에 영향을 줄 수 있어 필요할 때만 추가 취득한다.
5. 현재는 선택 창고 한 곳–선택 구호소 한 곳 왕복이다. 세 구호소 공유 차량의
   동시 배정·다중 하역 순회는 별도 확장이다.

`official_geometry_scenario`, `operational_ready=false`를 유지한다. 기관 승인이나
전국 최적성을 주장하지 않는다. 원본 ZIP·LFS 모델·예측 학습/홀드아웃은 변경하지 않았다.
